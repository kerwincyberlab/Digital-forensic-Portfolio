# ExifTool Image Metadata Examination

## Project Overview
A beginner digital forensics practical using ExifTool to examine image metadata.

## Tool Used
- ExifTool 13.64

## Activities Performed
- Examined image metadata.
- Extracted image width and height.
- Checked file name, file type and MIME type.
- Examined available date and time information.
- Generated a metadata report.

## Key Finding
ExifTool identified the practice image as PNG, even though its filename had a .jpg extension.

This demonstrated the importance of verifying the actual file format instead of relying only on the file extension.

## Evidence
Screenshots and the metadata report are included in this project.

## Learning Outcome
I gained practical experience using ExifTool and Windows Command Prompt to examine image metadata.
